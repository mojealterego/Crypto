# OMEGA Sovereign Swarm — Android

Repozytorium przeznaczone na aplikację Android do nadzoru nad rojem wydobywczym.

Bezpieczeństwo: tryb symulacyjny domyślnie; polecenia sterujące tylko przez zatwierdzoną bramę HTTPS, podpisy StrongBox P-256 i lokalne ograniczenia sprzętowe. Repozytorium **nie jest** dowodem wdrożenia ani zbudowania APK.

Projekt źródłowy Android Studio oraz moduły testowe przygotowywane są jako niezależny pakiet do weryfikacji przed wdrożeniem.
